כניסת מנהל

הגדרה חד־פעמית (כדי לעדכן את כולם)

1. היכנס ל־jsonbin.io ופתח חשבון חינם
2. Create Bin → הדבק את תוכן המחירים (או Bin ריק) → Create
3. העתק את ה־Bin ID (בכתובת / מהמסך)
4. API Keys → העתק Access Key (X-Master-Key)
5. הדבק כאן ולחץ שמור הגדרות
