חיבור לגיטהאב (פעם אחת)

כדי לפרסם בלחיצה אחת צריך Personal Access Token עם הרשאת repo.

איך מייצרים טוקן:
1. GitHub → Settings → Developer settings → Personal access tokens → Tokens (classic)
2. Generate new token (classic) · סמן repo
3. העתק את הטוקן לכאן ולחץ "שמור טוקן במכשיר"
הטוקן נשמר רק בדפדפן שלך (localStorage), לא באתר.
